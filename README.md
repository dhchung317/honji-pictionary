# Honji Pictionary
### Made with React + TypeScript + Vite
---
POC pictionary game - live at https://honji.xyz/

Compete to see who draws the best!

### How to play
---

Host a new game at https://honji.xyz/

Players enter their name and room code at https://honji.xyz/join

Hosts can start when everyone has joined 

Players have a time limit to draw the prompt

Once game is over you can see the results
